# Gizemli Gecikme Mazereti Jeneratörü

**DİKKAT:** Bu depo insanlığın en büyük sorununa çözüm getirir. Geç kaldın mı? Artık sorun yok. Bilimsel, felsefi ve biraz da şizofrenik mazeretler üretiyoruz.

## Neden Bu Proje Var?

Çünkü hayatta en önemli şey zamanında olmak değil, geç kalmanın *nedenini* epik bir şekilde anlatabilmektir. Bu jeneratör, NASA'da çalışan köpeklerin bile kullanacağı kadar ciddi bir algoritma kullanır.

## Kullanım

```bash
python mazeret_jeneratoru.py
```

Bir mazeret çıkar. Patronuna oku. Kahraman ol.

## Özellikler

- %100 gerçekçi (hiç değil)
- Türkçe (zorunlu)
- Patates yok (söz verdik)
- Sonsuz mazeret (asla bitmez)
